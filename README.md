# BIBLIOTECA SECRETA: BROMAS INFORMÁTICAS & LESSWARES (v2.0.0)

¡Bienvenido a la biblioteca secreta de scripts, ejecutables y travesuras digitales! Este repositorio contiene una colección masiva de herramientas diseñadas para asustar un rato a tus amigos, simular pantallas de error míticas, alterar periféricos o trolear el comportamiento del sistema operativo Windows.

> ⚠ **DISCLAIMER:** Bromas simples, no se las pongas a nadie (o sí, pero bajo tu propio riesgo). Úsalo con moderación y solo con fines de entretenimiento entre amigos.

## REGLA DE ORO DE SEGURIDAD
**Todos los ejecutables y lesswares modernos de este repositorio se cierran de golpe manteniendo pulsada la tecla SHIFT (Mayús) en tu teclado.** El detector lee directamente el hardware de la máquina, actuando como un freno de mano instantáneo. 

*(Excepción: Los antiguos archivos `.vbs` o scripts por lotes que requieren matar el proceso desde el Administrador de Tareas `Control + Shift Izq. + Esc`).*

## Estructura Completa del Repositorio

El proyecto se encuentra organizado meticulosamente en base a las siguientes categorías y carpetas:

### 1. `⚠DANGER⚠` (¡MUCHO CUIDADO!)
* **`cazafantasmas.exe`**: Código heredado j****do de verdad. No lo ejecutes a la ligera porque puede congelar el sistema de forma crítica, saturar componentes o forzar reinicios persistentes. Úsalo bajo tu absoluta responsabilidad.

### 2. `Favoritos` (La Selección de Éxito)
* **`cut_me_off.exe`**: Fiesta asegurada, literalmente, y susto para el dueño, por los destellos y la música.
* **`giantmouse.exe`**: Multiplica el tamaño del cursor del ratón hasta volverlo gigante, se sale pulsando espacio 10 veces (no, no es verdad, es con Shift pero decir eso, porque cada vez que se pulsa el espacio aparece un nuevo mouse vagabundo).
* **`Pantas arriban.exe`**: Voltea la orientación de la pantalla de forma repentina, la verdad es que es un buen reto de orientacion si lo tomais así.
* **`taaarrtamuudddddoo.exe`**: Añade un retardo aleatorio y tartamudeo sintético a las pulsaciones del teclado, es buenísimo.

### 3. `Hacks` 
* **`bypass.bat`**: Script en lotes que hace que cualquier script que neccesite privilegios de admin. se ejecute si lo arrastras dentro (no es mio, gracias al creador @ÉbolaMan-YT ).
* **`Comandos CMD.txt`**: Unos comandos para ejecutar en redes como las del colegio, obivamnete, no lo hagais en el colegio (o sí, hallá vosotros).

### 4. `Lab` (El Laboratorio Experimental)
* **`Creator.py`**: El motor en Python encargado del diseño de los lesswares, trnasformandolo en un exe directo.
* **`documento_estandar.py`**: Script base que estructura la arquitectura, es un simple txt vacía con el útlimo lessware.
